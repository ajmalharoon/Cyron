03

Questions, answered.

What's the difference between active and passive?

Active phases send traffic to the target — port scans, HTTP requests, directory brute-forcing. Passive phases read public sources, archives, and your own cloud or repository accounts, and send nothing to the target itself.

Is anything exploited or changed on the target?

No. Cyron only gathers information. It does not attempt exploitation, credential guessing, or denial-of-service testing, in either mode.

How is severity decided?

Each tool module rates its own findings using simple, documented heuristics (open admin paths, exposed secrets, deprecated TLS, and so on) or passes through a severity the tool itself reports, like Nuclei's template severity. These are Cyron's automated judgement, not CVSS scores — an analyst should confirm every finding before acting on it.

Can I add my own tool?

Yes. Subclass ToolRunner in backend/app/recon/tools/, register it on a phase in backend/app/recon/registry.py, and it appears in the UI automatically — the frontend reads the phase list from the API.

Where does the report come from?

The backend builds it from the findings stored for the scan, once the scan completes. It's generated fresh each time you open the Report tab for a finished scan.

Authorized use only. Run Cyron only against systems you own or have explicit written permission to test.
